## Anthropic Economic Index Capstone
This project uses the Anthropic Economic Index, an open dataset that describes how Claude is used across work tasks, occupations, interaction styles, and enterprise API usage.

## Dataset:
https://huggingface.co/datasets/Anthropic/EconomicIndex

## Research paper:
https://arxiv.org/abs/2503.04761

## Research Question:
Do consumers using Claude.ai and businesses using the enterprise API differ in how they use AI on the same work tasks, particularly in their use of automation versus augmentation?
